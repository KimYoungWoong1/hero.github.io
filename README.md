## Featured Projects

### AMI Meeting Highlight Detection

A multimodal research pipeline for meeting highlight detection on AMI meeting data. The project covers AMI XML parsing, Master Feature Sheet construction, manual GT candidate generation, human review support, GT generation model training, pseudo-labeling, final summarization model training, raw-video inference, benchmark comparison, and ablation study.

Repository: https://github.com/byungkun0823/ami-highlight-project

### CAVE: Credibility Audit for AI-Generated Evidence

A local web demo for auditing AI-generated images and deepfake videos in digital evidence scenarios. CAVE combines provenance checks, watermark and metadata signals, AI detector ensembles, rPPG biometric signals, generator fingerprint attribution, cross-layer audit, and GNN-based harm assessment.

Repository: https://github.com/KimYoungWoong1/CAVE

### Nymeria HAR Dataset Construction

A dataset construction pipeline that parses natural-language activity annotations, maps them to UCI/UCA-style HAR labels, and crops matching IMU windows into labeled human activity recognition segments.
